# Music and Concert SQL Practice

## Overview

A small SQL practice repository containing two scripts built around music-related data:

- `bestsongs.sql`: creates a table for favorite songs and practices inserting, querying, checking for duplicates, and defining uniqueness constraints.
- `concerts.sql`: creates a concert table and practices inserting attendance records, filtering, counting, and grouping records by artist or venue.

## Concepts practiced

- Creating tables and choosing column types
- Inserting records
- Selecting and filtering data
- Aggregate functions such as `COUNT`
- Grouping records with `GROUP BY`
- Identifying duplicate records
- Primary keys and unique constraints
- Deleting and modifying records

## Tools

- SQL
- MySQL

## Notes

These scripts represent learning exercises and are not yet packaged as a reproducible database project. They reference database names that must exist in the local MySQL environment. Some statements may need correction before execution; for example, the scripts should be reviewed for primary-key conflicts, aggregate-query syntax, and duplicate-removal logic.

No production database or external service is required. Review each statement and run it in a test database rather than against important data.
